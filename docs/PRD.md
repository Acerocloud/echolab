## 1. 背景与问题

### 1.1 用户的真实痛点

| # | 痛点 | 现象 |
| --- | --- | --- |
| P1 | 输入多、输出零 | 刷了几百条视频，开口还是卡；"听懂"停留在阅读字幕 |
| P2 | 没有可模仿的颗粒度 | 整段跟读跟不上，逐词跟读又丢了语调；缺"一句一个循环"的工具 |
| P3 | 不知道自己差在哪 | 录了音，但听不出自己与原声在重音、连读、节奏上的差别 |
| P4 | 素材门槛高 | 想练的访谈/公开课没人做字幕；自动字幕错一个词，跟读就跟着错 |
| P5 | 工具打断心流 | 广告、点数、弹窗、跳转，练 3 句就想关掉 |

### 1.2 为什么是 shadowing / 回音法

- **Shadowing（影子跟读）**：边听边说，训练"同步处理"与反应速度，是同传的基础训练。缺点是跟不上时会牺牲发音细节。
- **回音法（Echo Method，台大外文系 史嘉琳 提出）**：听完一句 → 停顿，让声音在脑中"回响" → 再模仿说出。多了一个"回忆"环节，专门校准语调、连读与节奏。
- **EchoLab 的判断**：两者不是二选一，而是**同一工作台的两个档位**。默认用回音法打地基（有停顿、无压力），熟练后切成同步跟读（无停顿、拼速度）。

## 2. VoiceTube 功能拆解

### 2.1 产品定位

> "用真实影片学英文" —— 把 YouTube / CNN / TED 的海量视频，包装成带双语字幕、可查词、可跟读的教材，再叠加 AI 发音评分与复习系统，用订阅（Pro）和点数（Energy）变现。

它本质上是 **内容平台（海量视频）+ 学习工具（字幕/查词/跟读）+ 复习系统（单词/句子测验）** 的三层结构，护城河在**内容量与本地化（中/日/越语界面、双语字幕）**。

### 2.2 信息架构

```
首页（编辑精选 / 热门标签 / 主题频道 / 搜索 / 筛选：时长、程度、口音）
├── 影片页（播放器 + 学习区）
│   ├── 播放器：单句循环、上一句/下一句、倍速、字幕开关、字体大小、快捷键
│   ├── 双语字幕：中/英/日 独立开关，点击查词，整句收藏、佳句高亮
│   ├── 学习区：用法解析、单词表（按难度/考试筛选）、收藏、Quiz
│   └── 口说练习（跟读工作台）：Auto/Manual、回音法开关、AI 发音分析
├── 收藏/学习簿：收藏影片、单词、句子；复习（听英翻中 / 中翻英 / 句子重组）
├── 口说挑战：每日一句、社群作品
├── 学习历程：时长、连续天数、程度评测
└── 会员：Pro（无限点数、导入影片、无限发音分析）、Energy 点数、广告
```

### 2.3 核心学习闭环

```
选片 → 看（双语字幕）→ 查词/收藏 → 逐句听 → 跟读（录音）→ AI 评分 → 复习 → 数据反馈 → 推荐下一支
```

这个闭环**设计得对**，但每一环都有摩擦力（见 2.5）。

### 2.4 功能清单拆解

| 模块 | 功能 | 设计意图 | 我们的取舍 |
| --- | --- | --- | --- |
| 内容 | 10 万+ 影片、每日更新、TED/BBC/CNN/美剧/音乐 | 用兴趣降低流失 | ✅ 保留（但改为精选小库，宁少不滥） |
| 内容 | CEFR 分级 A1–C2、时长筛选、口音筛选 | 匹配难度，防挫败 | ✅ 保留 |
| 内容 | 导入 YouTube 链接自动生成字幕 | 无限扩展教材 | ⏸ P2（自动字幕错误率与 shadowing 冲突） |
| 字幕 | 中/英/日 双语独立开关、字号、位置 | 沉浸 vs 辅助的平衡 | ✅ 保留（默认「英上中下」） |
| 字幕 | 逐句列表点击跳转、自动滚动、单句循环 | 把视频变成可操作的文本 | ✅ 保留，且做成核心 |
| 字幕 | 整句收藏 / 佳句高亮 / 打印字幕 | 沉淀与复习 | ✅ 收藏；打印 ⏸ |
| 查词 | 双击/长按查词、发音、例句、一键收藏 | 降低查词中断成本 | ✅ 改为「语境词卡」：本课出现位置优先 |
| 播放 | 0.75x 慢速、A-B 循环、快捷键 | 降低模仿门槛 | ✅ 保留 + 0.5x/0.75x/1x/1.25x |
| 跟读 | 单句录音、原声回放、AI 逐词/音节评分（绿/红，80/70/60 分档） | 给即时反馈 | ⚠️ 降级为「可选」：本地无法保证识别服务 |
| 跟读 | Auto / Manual 模式、回音法（Listen→Echo→Speak→Playback） | 引导练习节奏 | ✅ **核心**，做成状态机 |
| 复习 | 听英翻中、中翻英、句子重组、单词测验 | 抗遗忘 | ⏸ P1（句子重排 + 本课词测） |
| 数据 | 学习时长、连续天数、程度雷达 | 成就感 | ✅ 简化版：句数/分钟/连续天数 |
| 商业化 | Pro 订阅、Energy 点数、广告 | 变现 | ❌ 不做（本地、免费、无账号） |
| 社交 | 口说挑战、社群点赞 | 外部动机 | ❌ 不做（MVP 不引入社交负担） |

### 2.5 拆解结论：它做对了什么、哪里对 shadowing 不够

**做对了**

1. **"逐句"是正确的最小单位**：把连续语音切成可操作的句子，才有了循环、变速、跳转、跟读。
2. **双语字幕分层**：中文负责理解，英文负责模仿，两者可以独立开关。
3. **回音法被产品化了**：把方法论变成 4 个步骤的状态机，用户不用自己想"下一步做什么"。

**对 shadowing 不够的地方**

| 问题 | 具体表现 | EchoLab 的解法 |
| --- | --- | --- |
| 反馈是黑盒 | 只给一个分数和红绿词，不告诉你"节奏慢了 0.4 秒""重音错了" | **波形对比**：把你的录音与原声的能量包络叠在一起，看得见节奏差 |
| 缺"叠加回放" | 只能先听原声、再听自己，两次播放之间靠记忆对比 | **A/B/X 三段回放**：原声 / 我的 / 同时叠放，一键切换 |
| 练习不沉淀 | 练完就散，没有"今天该复习哪 5 句" | 每句有 **熟练度**（新→练过→过关），下一次自动排到队首 |
| 心流被打断 | 点数、广告、会员墙 | 无账号、无广告、录音不离开本机 |
| 素材不可信 | 导入视频靠自动字幕，错词会让跟读学错 | **只收录带人工字幕的素材**，并在页面标注字幕来源 |

## 3. 产品定位与取舍

### 3.1 定位

> **一个"只有跟读"的网页工作台**：选一句真实语料 → 听 → 回声 → 说 → 对比 → 过关。
> 不是视频网站，是**练习器**。视频只是"原声的载体"。

### 3.2 目标用户

| 画像 | 场景 | 关键诉求 |
| --- | --- | --- |
| 备考党（雅思/托福口语） | 每天固定 15 分钟，练 Part 2 的叙述节奏 | 需要短、可重复、能看到进步 |
| 职场人（面试/汇报） | 通勤后用电脑练 3–5 句 | 需要"体面"的语料（TED/访谈） |
| 兴趣学习者 | 追 TED、科普 | 需要内容有趣、难度可筛 |

### 3.3 差异化假设（可验证）

1. **看得见的对比 > 打分**：波形叠加比"78 分"更能指导下一次模仿。
2. **少而准 > 多而杂**：30 句人工校对语料，好过 300 句自动字幕。
3. **零门槛 > 完整账号体系**：打开即练，进度存本地。

### 3.4 明确不做（MVP）

- ❌ 账号体系、云同步、社交
- ❌ AI 发音评分作为**必要条件**（作为可选项，见 P1）
- ❌ 视频上传/转码后台
- ❌ 移动 App

## 5. 核心流程规格

### 5.1 主流程

```
首页课程库
  └─ 点卡片 → 课程播放页（视频 + 逐句字幕）
        ├─ 自由观看/精听：单句循环、变速、查词、收藏
        └─ 点「开始跟读」→ 跟读工作台（全屏、沉浸）
              └─ 逐句循环：听→回声→说→对比→自评
                    ├─ 过关 → 下一句
                    └─ 再来 → 同一句重录（计数 +1）
                          └─ 练完 → 结算页（分钟数/过关句/薄弱句）
```

### 5.2 跟读工作台状态机（P0 核心）

```
        ┌──────────────────────────────────────────────┐
        │                                              │
   [IDLE] --播放原声--> [LISTEN] --句末--> [ECHO] --倒计时--> [RECORD]
        ^                                   |                    |
        |                                   |(回音法关闭)         | 用户停止/超时
        |                                   v                    v
        |                                [RECORD] ----------> [REVIEW]
        |                                                         |
        └---------------- 重听/重录 <----------------------------┘
                                                                  |
                                                          自评「过关」
                                                                  v
                                                              [NEXT] → 下一句
```

| 状态 | 界面 | 允许操作 |
| --- | --- | --- |
| LISTEN | 大字号句子，播放中高亮当前句 | 暂停、重听、跳过 |
| ECHO | 显示"回声 3…2…1"，句子保持可见 | 跳过停顿、直接录 |
| RECORD | 录音按钮脉冲，实时波形 | 停止、取消 |
| REVIEW | 双波形对比 + 三个回放按钮 | 原声/我的/叠加、重录、过关 |

**时间参数**

- 回声停顿：默认 3s，可在设置中调 1–5s（关闭回音法时为 0）
- 录音最长时长：`min(句子时长 × 1.8, 20s)`，到点自动停止
- 句末静音检测：暂不做（浏览器端不稳定），用"用户点击 + 超时"兜底

### 5.3 判定与自评

MVP **不做机器判分**，理由：

1. 浏览器端 ASR 依赖联网服务，中文网络环境下不可靠；
2. 分数会诱导用户"刷分"而不是"模仿"。

替代方案：**自评 + 可观测证据**

- 用户听三段回放后自评：`再来一次` / `过关`
- 证据留在界面上：两条波形、本句重复次数、总练习时长
- P1 再叠加可选 ASR 词级 diff（仅作辅助提示，不阻断流程）

## 6. 页面与交互规格

### 6.0 视觉原则（v0.2 起）

- **扁平**：不用渐变、发光、玻璃拟态、厚投影；层次靠留白、字号与极细分割线建立。
- **克制**：全站一个强调色（系统蓝 `#0071e3` / 暗色 `#0a84ff`），其余为中性灰阶。
- **大字与留白**：首页以排版为主，不做「主打视频」式首屏；课程信息用层级而不是卡片堆叠。
- **圆角与胶囊**：卡片 18px，按钮与筛选器一律胶囊形（980px）。
- **单一深色**：纯黑底（`#000`）+ `#1c1c1e` 面板，`color-scheme: dark` 让原生下拉/滚动条也走深色。不做浅色主题——两套配色最容易在原生控件上翻车。

### 6.1 页面清单

| 路由 | 页面 | 关键内容 |
| --- | --- | --- |
| `#/` | 课程库 | 大标题 Hero（不绑定具体视频）+ 数据条 + 筛选 + 卡片网格 |
| `#/words` | 生词本 | 生成条（5–50 句 + 按钮）→ 逐句卡片（AI 新句 / 听整句 / 看译文 / 记住了）；下方全部生词 |
| `#/lesson/:id` | 课程页 · 精听 | 左：YouTube 播放器 + 课程信息；右：播放控制条 + 双语逐句列表 |
| `#/lesson/:id/shadow` | 课程页 · 跟读 | **同一页面**右栏换成跟读面板，播放器保持可见 |
| `#/progress` | 学习记录 | 连续天数、总时长、过关句、热力图、各课进度、生词本 |
| `#/settings` | 设置 | 字幕、回声时长、主题、快捷键表、数据重置 |
| `#/about` | 关于 | 素材来源、版权说明、方法论 |

### 6.2 播放器规格

- 视频：`<video>` + 自定义控制条（播放/暂停、时间、进度、音量、倍速、全屏）
- **不用原生字幕轨**：字幕由 JS 按 cue 渲染，便于逐句高亮、双语分层、点击查词
- 单句循环：`timeupdate` 中 `if (repeat && t >= cue.e) seek(cue.s)`
- 逐句列表：`aria-current` 标记当前句；`scrollIntoView({block:'center'})`，但用户 3s 内手动滚动过则不抢
- 倍速：0.5 / 0.75 / 1 / 1.25 / 1.5，持久化

### 6.3 跟读面板规格（同屏，不跳页）

- 位置：课程页右栏（桌面 402px），顶部有「精听 / 跟读」分段控件切换；**视频始终留在左栏**
- 内容自上而下：句序 + 范围/模式/收藏 → 句子（英文大字 + 中文）→ 四步进度 → 波形 → 录音主操作 → 状态行 → 三段回放 → 自评 → 句序圆点
- 布局：视频栏按 16:9 自适应；跟读面板宽度不随视频伸缩，保证按钮位置稳定
- 波形：`AnalyserNode` 分别采样原声与麦克风的 RMS，归一化后叠画（蓝=原声，橙=我的）
- 叠加回放：原声 `video` 与录音 `Audio` 同时播放，误差 < 50ms
- 键盘：`Space` 播放/停止，`R` 重录，`1/2/3` 三段回放，`↵` 过关，`←/→` 上下句

### 6.4 词卡规格

- 触发：字幕中点击单词（长按在移动端）
- 内容：单词、音标（内置小词表命中时）、TTS 发音、本课出现次数、3 条本课例句（点击跳转）、收藏
- 降级：无内置词条时只显示 TTS + 语境例句（**不联网也能用**）

## 8. 内容策略

### 8.1 选材标准（硬性）

1. **必须有人工字幕**（YouTube "Available subtitles" 中的 `en`，而非 automatic captions）。这是"自动字幕不出错"的唯一保证。
2. 英式/美式均可，单口播或访谈；语速 130–180 wpm。
3. 单课 3–7 分钟；整段讲一个完整意思（可节选，但首尾要能自洽）。
4. **授权可用**：TED / TED-Ed 为 CC BY-NC-ND 4.0，Big Think 为平台公开内容；页脚统一标注来源与许可，仅用于个人学习。

| 修法 | 程序化跳转后记一个 `pendingSeek`，期间不重算当前句，直到真实时间落进目标句（±60ms 容差）才解除；`cueAt` 改为严格命中优先；落地后短暂锁定目标句 600ms；补一次播放确认（用户手动暂停会作废） |
