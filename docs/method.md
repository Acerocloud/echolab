# 影子跟读怎么练（以及 EchoLab 为什么这么设计）

## 1. 两种方法，一个目标

**Shadowing（影子跟读）**
边听边说，声音几乎与原声同步。训练的是「同步处理」能力——耳朵还在接收下一句时，嘴已经在复述上一句。同声传译的基本功。
代价：跟不上时会**牺牲细节**，为了不掉队，发音、重音、连读常常被含糊带过。

**回音法（Echo Method）**
台大外文系史嘉琳教授提出。在「听」和「说」之间插入一段**停顿**：
听完一句 → 停下来，让声音在脑中回响（echo）→ 再开口模仿。
多出来的这几秒，正是用来抓语调、重音、连读和节奏的。

> 一句话区别：Shadowing 练「跟得上」，回音法练「像不像」。
> 基础不牢时先练回音法，稳定之后再切同步跟读。

EchoLab 把两者做成同一个工作台的两个档位，随时切换。

## 2. EchoLab 的四步

| 步骤 | 你在做什么 | 界面在做什么 |
| --- | --- | --- |
| **听** | 只听这一句，别急着开口。抓三件事：重音落在哪、哪里连读、哪里停顿 | 只播放当前句，进度条走完自动停 |
| **回声** | 闭眼，把刚听到的声音在脑子里重放一遍（默认 3 秒，可在设置里改 1–5 秒） | 倒计时，屏幕不给新信息，逼你回忆 |
| **说** | 照着脑子里的回声说一遍，不要用你习惯的念法 | 录音，实时波形，最长 1.8 倍句长 |
| **对比** | 依次听：原声 → 我的 → 叠加。看两条波形哪里不重合 | 双色包络叠画（青=原声，橙=我的） |

「叠加」是关键：同时播放原声与你的录音，像合唱。差半拍、重音错位，会立刻听出来——这比任何分数都直接。

## 3. 每天 10 分钟怎么排

1. **0:00–2:00** 选一段 3–6 分钟的材料（比如「Grit」或 TED-Ed 科普），先整段看一遍，中英字幕都开。
2. **2:00–8:00** 进跟读工作台，只练 8–12 句。每组：听 → 回声 → 说 → 对比，同一句最多重复 3 次。
3. **8:00–10:00** 回到课程页，把刚才练过的几句**不看字幕**再听一遍；听不懂的句子点「收藏」。

> 句子数不重要，**「过关」的质量**才重要。判断标准不是"我念完了"，而是"叠加播放时，两条波形几乎重合、听不出两个声音"。

## 4. 常见错误

| 错误 | 后果 | 改法 |
| --- | --- | --- |
| 看着字幕念 | 练的是朗读，不是听力 | 先盲听一遍再显示字幕；用 `H` 隐藏字幕 |
| 语速太快 | 吞音、连读全丢 | 0.75× 慢放，先求准再求快 |
| 一直用同一句 | 变成背诵，失去即时处理 | 过关就下一句；「再来一次」最多 3 次 |
| 只练不听 | 没有对比就没有修正 | 必须听完「三段回放」再自评 |
| 音量太小 | 波形几乎是一条线，看不出节奏 | 离麦 15–20cm，正常音量 |
| 外放 + 录音 | 麦克风把原声也收进去，叠加变成回声 | 戴耳机 |

## 5. 为什么没有「发音打分」

v0.1 刻意不做机器评分，原因有三：

1. 浏览器端的语音识别依赖联网服务，在中文网络环境下不稳定，时好时坏会让练习节奏断裂；
2. 分数很容易变成新的目标——用户会去「刷分」，而不是「模仿」；
3. 打分给的是结论，波形给的是**证据**。看得见自己比原声慢半拍，比看到「78 分」更有用。

后续版本会以**可选**的方式加入词级识别对比（漏读 / 多读 / 错读），且不阻断主流程。

---

## 6. 什么时候算「可以了」

- 叠加播放时，两条波形起落基本同步；
- 不看字幕也能跟上原速；
- 换一句新的、同难度的句子，第一次就能模仿出大致节奏。

到这一步，就可以把模式切到「同步跟读」，练真正的 shadowing 了。
